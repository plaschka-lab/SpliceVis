Dashboard Documentation

features, UI, and curation methodology

Scope

SpliceVis is a public atlas of deposited spliceosome and spliceosomal snRNP structures. It combines an interactive, consistently colored 3D viewer with RNA annotations, reference alignments, literature links, and ready-to-run ChimeraX scripts.

  • The web viewer retrieves deposited coordinates on demand; large coordinate and map files are not bundled with the web interface.
  • The primary-map ChimeraX script can request the associated primary EMDB map.
  • Entries are organized by pathway state, species, publication, resolved components, pre-mRNA substrate, RNA annotations, validation data, and homolog/color metadata.

Atlas Workflow

The Atlas is the main structure-browsing workspace.

  • Search by PDB accession, title, state, author, species, or component; use Refine for state, species, pre-mRNA substrate, RNA-feature, and sorting controls.
  • Click a pathway sector to restrict the associated-structure table, then select a row to load its Mol* model and RNA alignment.
  • Use the RNA-element and protein controls to focus the 3D model. External resources, curation and validation details, RNA files, and comparison tools remain available below.
  • On small screens, switch explicitly between Cycle, Structures, and Selected structure views.

RNA Features

Resolved substrate and snRNA features are assigned from deposited sequences and coordinates, reference alignments, state-specific interaction evidence, and documented manual curation.

  • Use Refine to filter the atlas by annotation coverage or a specific RNA feature.
  • The selected-structure alignment places all deposited substrate chains against the assigned annotated reference and distinguishes modelled residues from unresolved sequence.
  • Named ChimeraX selectors follow `stage_PDB_feature`, for example `pre_Bact_7AAV_5exon`; segments belonging to one biological feature are combined into one selection.
  • A missing selector means no resolved interval met the current annotation rules, not necessarily that the biological feature is absent.

Pre-mRNA Substrates

Construct identities use an evidence hierarchy: explicit deposited names and manual curation, exact full-sequence or annotated-intron propagation, then high-identity alignment to literature-defined reference constructs. Weak calls remain unspecified and review-required. Recurrent named families provide an annotated GenBank reference, a reference-anchored multiple-sequence alignment showing which residues are modelled in each structure, and a table projecting each reference feature onto deposited polymer sequences. These projections are exposed for audit and manual curation; they do not silently overwrite structure-level feature annotations.

Components and Colors

This reference view exposes the universal color table, preferred component names, aliases, homolog mappings, systematic chain IDs, and provenance metadata.

  • Its search is independent of the Atlas search and accepts protein names, homologs, aliases, and systematic chain IDs.
  • Curated high-level component groups replace raw, overlapping source classifications in the filter.
  • The dashboard defaults to deposited chain IDs and can optionally rename chains in-session before coloring, alignment, and named selections are applied.

ChimeraX Scripts

Public scripts use `open PDBID` commands so ChimeraX retrieves models directly from the PDB. The selected-structure panel offers a systematic-chain-ID checkbox for users who prefer harmonized chain identifiers.

  • Scripts use unique model IDs so multiple structures can be opened in one ChimeraX session.
  • In systematic-chain mode, deposited chain IDs are renamed live with two model-scoped `changechains` commands: all deposited IDs first move to temporary safe-harbor IDs, then those temporary IDs move to the systematic project IDs. This avoids collisions when a target ID already exists in the deposited model.
  • Structures are aligned to a shared anchor frame where PRPF8/SF3B1-compatible anchors are available.
  • Scripts apply the shared color code, RNA feature named selections, default display style, and nucleic-acid visibility after the requested chain-ID mode has been established.
  • GUI ChimeraX runs fetch a self-contained named-selection browser from GitHub; clicking an entry selects and zooms the corresponding RNA feature, and RNA-feature rows include checkboxes to toggle their 3D labels. No-GUI runs skip the browser automatically.
  • The model-only variant loads coordinates only; the primary-map variant also downloads the deposited primary EMDB map and brings it with the aligned model where ChimeraX can move the opened volume model.

Methods-Style Curation Methodology

SpliceVis is generated by scripts that combine public structural metadata, deposited coordinate files, EMDB records, curated spliceosome knowledge, and validation data. Reproducible releases should report the metadata snapshot, software commit, discovery queries, and manual overrides together with exported results.

Structure Discovery And Inclusion Criteria

Candidate PDB entries were identified through recorded PDBe/PDB searches seeded with PRPF8/Prp8- and SF3B1/Hsh155-containing spliceosomes, then expanded by title, polymer composition, publication context, reference-database seeds, and manual review. This expansion captures spliceosomal snRNP assemblies, model-organism spliceosomes, early complexes that lack the initial protein anchors, and relevant X-ray as well as cryo-EM structures. An entry was retained when its deposited title, composition, publication, or curated inspection supported assignment to a spliceosomal assembly or pathway state. Only released PDB entries appear in the public dataset.

Primary Metadata Extraction

Titles, release and revision dates, experimental methods, nominal resolutions, linked EMDB accessions, publication identifiers, journals, years, organisms, and polymer entities were obtained from PDB/PDBe and EMDB records. Chains, sequences, molecule and gene names, polymer types, and UniProt cross-references were parsed from deposited mmCIF files and PDBe entity records. Missing metadata are reported as unavailable rather than inferred.

Splicing-Pathway Assignment

Structures were assigned to curated pathway bins by ordered title- and publication-derived rules, followed by manual correction of known ambiguous cases. Categories include isolated snRNP states, E, A, U5/tri-snRNP, pre-B, B, pre-Bact, Bact, B*, C, C*, P, ILS, DIS, U5 recycling, and the B*D quality-control/discard group. DIS is positioned as the first recycling state after ILS. Ambiguous labels such as pre-B versus P are flagged and resolved from publication and component evidence. These labels are curated atlas bins, not necessarily depositor-supplied state names.

Protein And RNA Component Annotation

Deposited entity names and gene symbols provide the initial component labels. UniProt cross-references, curated aliases, species-specific homolog tables, publication evidence, OMA/BLAST-supported assignments for model organisms, and manual corrections are then integrated to normalize names for search and coloring. RNA identities additionally use chain context and sequence evidence. Unrecognized or conflicting entities remain explicitly unresolved and are exposed by the curation audits.

Homolog Mapping

Homologous proteins across human, S. cerevisiae, S. pombe, C. elegans, and Chaetomium thermophilum were mapped to human-centric color and family keys where possible. Evidence can include a species-self match, curated aliases, publication text, OMA orthology, reviewed BLAST best hits, and consistent name or color-key matches. Ambiguous or unmatched components remain flagged. Repeated Sm/LSm copies are distinguished using snRNP context and proximity to the cognate snRNA when deposited identity alone is insufficient.

RNA Feature Annotation

Resolved substrate and snRNA features were assigned using deposited component names, author residue numbering, sequence motifs, splice-site inference, annotated-reference alignments, interaction-network evidence, and resolved-residue checks against mmCIF atom sites. Substrate features include the two exons, splice sites, intron, branch region and branch-point adenosine, polypyrimidine tract, ligated exons, and intron lariat. snRNA features include conserved substrate-recognition, snRNA-snRNA, catalytic, and Sm/LSm-binding regions in major and minor spliceosomes. Each feature retains method and confidence metadata; review-region and low- or medium-confidence intervals are approximate. A missing feature means that no resolved selectable interval met the current rules, not that the biological feature is absent. Named selections combine discontiguous segments or chains that represent one biological feature.

EM Map Enumeration And Availability

Primary and associated EMDB accessions are collected from PDB and EMDB cross-references, including focused refinements and additional maps where listed. Map provenance is tracked separately from file availability. Map binaries are not distributed through GitHub Pages; the primary-map ChimeraX script requests the deposited primary EMDB map on demand.

ChimeraX Script Generation And Alignment

Public scripts use ChimeraX `open PDBID` commands and retain deposited chain IDs by default. Optional systematic IDs are applied in two model-scoped steps through temporary safe-harbor identifiers before colors and named selections are created, avoiding chain-ID collisions. Model IDs are unique per structure, and compatible structures are aligned to a shared frame using PRPF8- or SF3B1-family anchors. Scripts apply the shared display style, component colors, RNA-feature selections, sequence-alignment viewer, nucleic-acid visibility, and optional primary-map loading.

Color Assignment

Protein and RNA colors are visualization conventions, not evidence for identity. Curated colors from the project reference scripts were retained where available; missing entries were assigned with family-aware palettes so homologous proteins and related spliceosomal modules remain visually coherent. Color provenance distinguishes inherited, curated, and generated assignments.

Quality Metrics And Validation Data

Nominal/map resolution, model-validation summaries, and Q-score values are extracted from PDB/PDBe and EMDB validation records when available. Acquisition descriptors, including resolution method, pixel spacing, map box size, particle count, microscope, and detector, are shown only as context and do not contribute to curation or quality badges. These fields are screening aids and do not replace inspection of validation reports, local resolution, model-map fit, or deposited maps.

Audits And Confidence Labels

Automated audits track curation provenance, assignment confidence, data completeness, map provenance, homolog resolution, RNA identity, unresolved components, and repeated-substrate consistency. An unresolved component is a deposited entity that could not be normalized for dashboard use, most often a protein without a homolog/color assignment or an RNA without a supported identity; it is a curation-completeness issue, not a model-quality metric. Dashboard confidence labels are rule-based curation states, not calibrated probabilities. High confidence denotes deposited, manual, or independently supported assignments; medium confidence denotes rule-based or single-source inference; review denotes missing, conflicting, or heuristic assignments requiring inspection.

Local Copy

offline coordinates; maps optional

Model-Only Offline Install

Clone the public repository, then create a local dashboard folder with all public dashboard assets, helper scripts, thumbnails, RNA panels, and uncompressed coordinate mmCIF files. EM maps are not downloaded by default.

git clone https://github.com/plaschka-lab/SpliceVis.git
cd SpliceVis
python3 tools/setup_offline.py --dest ~/Documents/SpliceVis

Open Offline

The offline folder includes a small local-server launcher so the dashboard can load JSON and CXC files reliably in the browser.

cd ~/Documents/SpliceVis
./open_dashboard.command

Optional Maps

Primary EMDB maps are large and are treated as an add-on. Re-run the installer with the map flag only when local map support is needed.

python3 tools/setup_offline.py --dest ~/Documents/SpliceVis --with-primary-maps

Helper-Only Mode

For a smaller setup, clone the repository once, set ChimeraX helper scripts to Use local cloned repo, and enter the clone path. This avoids repeated helper downloads while still letting ChimeraX fetch PDB coordinates online.
